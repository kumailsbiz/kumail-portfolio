# Kumail Raza — Portfolio

Personal portfolio site for Kumail Raza, E-Commerce Executive & PPC Specialist.

Built with React + Vite.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This site is a static build (`npm run build` outputs to `dist/`) and can be deployed to GitHub Pages, Vercel, Netlify, or any static host.
